# S-26.05: Cut rc.26 Release (Ships #837 + AXIS-2 Batch + Removal + Fuel-Cap)

## Narrative
- **As an** operator running the vsdd-factory plugin against a live product
- **I want to** a single `v1.0.0-rc.26` release that carries the already-merged
  `validate-dispatch-advance` fix (#837), all three AXIS-2 hook-plugin defect fixes
  (#838/#839/#840), the `verify-state-timestamp-refresh` crate deletion, and the
  fuel-cap raise
- **So that** my operator-level marketplace-cached plugin install stops exhibiting all
  four defects and the dormant crate is gone from the shipped bundle, in one upgrade

## Problem Statement (release-vehicle story — closes #837 directly; #838/#839/#840 + removal require S-26.01..S-26.04 merged first)

Per CLAUDE.md's Architectural Authority: "The marketplace-tarball at
`~/.claude/plugins/cache/claude-mp/vsdd-factory/<version>/` is the operator-level
consumed copy... Source edits must be released for hooks to pick them up at the
operator level — develop-branch changes don't affect the cached plugin." AXIS-1's
fix (#837) is already merged to `develop` (commit `9a1d971b`, 2026-09-05) but has
never shipped in a release — rc.25 predates it by 2 commits. A release alone, cut
today, would close #837 and nothing else. Per the human-provided sequencing
directive, THIS story's dispatch is gated on S-26.01, S-26.02, S-26.03, and S-26.04
all having merged to `develop` first, so that rc.26 ships the COMPLETE batch — closing
all four issues plus the crate removal plus carrying the fuel-cap raise — in one
release, not a partial one.

- `develop` HEAD at release-cut time contains all four of S-26.01/S-26.02/S-26.03/
  S-26.04's merge commits as ancestors (confirms all three AXIS-2 fixes AND the crate
  removal are included).
- **Test:** Four `git merge-base --is-ancestor <story-PR-merge-SHA> <release-branch-HEAD>`
  checks, one per story, captured as release-checklist evidence

  `scripts/bump-version.sh`) explicitly lists all four issue numbers (#837, #838,
  #839, #840), the `verify-state-timestamp-refresh` crate removal (citing ADR-046
  §Decision 5), and the fuel-cap raise (citing ADR-042).
- **Test:** Manual review gate — release-cutter (devops-engineer) confirms the
  CHANGELOG entry before opening the `release/v1.0.0-rc.26` PR per RELEASING.md
