# VP-145: Closed Argument Grammar Rejection Invariant for backfill-append-logs

## Property Statement

Every invocation of the `backfill-append-logs` subcommand that does not EXACTLY match one of the
two ratified forms — `backfill-append-logs` or `backfill-append-logs --census` — is rejected
BEFORE any filesystem mutation occurs, with zero exceptions and zero fallback-to-permissive
behavior. This is a two-layer defense-in-depth property (BC-1.18.013 §Precondition 3, ADR-052
§Decision 3):

1. **Pre-shell classification (first layer).** The ADR-052 §Decision 5c full-command classifier
   rejects any Bash-tool dispatch whose command string does not resolve to exactly one of the two
   accepted invocation forms — a path argument, a `--cycle` flag, extra flags, shell metacharacters,
   or a compound command (`&&`, `;`, `|`, backgrounding) — BEFORE the binary is ever invoked.
2. **Binary-level rejection (second layer, defense-in-depth).** If the pre-shell classifier is
   somehow bypassed, the binary's own argument parser independently rejects any invocation outside
   the closed grammar with a non-zero exit code, per ADR-052 §Decision 3. Neither layer trusts the
   other to be the sole enforcement point.
3. **No cycle-directory argument, no glob, no auto-discovery — ever.** No accepted invocation form
   names a cycle directory, a path, or a wildcard; the four target files are the FIXED set named in
   ADR-052 §Decision 8's allowlist (BC-1.18.013 §Postcondition 6). This supersedes S-25.06's
   provisional AC-001(b) auto-discovery assumption. No implementation may add such an argument
   without a superseding ADR-052 amendment (§Invariant 5).
4. **Zero filesystem mutation on rejection.** A rejected invocation — at either layer — produces NO
   filesystem mutation of any kind: no flock acquired, no txn record written, no staging generation
   built, no canonical file touched.

## Source Contract

- **BC:** BC-1.18.013 §Precondition 3 / §Postcondition 6 / §Invariant 5 / §EC-008.
- **ADR:** ADR-052 §Decision 3 (closed argument grammar — binary-level enforcement), §Decision 5c
  (full-command classifier — pre-shell enforcement), §Decision 8 (POLICY 22 exception; the ratified
  allowed-write-targets allowlist naming the exact four files; wildcard/prefix explicitly rejected),
  §Decision 9 (resolves the S-25.06 Rule 7 contradiction — invocation is a `Bash` execution of a
  native binary under a closed argument grammar, never an Edit/Write tool call).
- **Precedent:** No direct sibling VP exists for BC-1.18.011 (B2's migration does not expose an
  equivalent closed CLI subcommand grammar at this layer); this is the first VP in the
  S-25.02/S-25.06 artifact-sharding family to cover ADR-052 §Decision 3's closed-grammar guarantee
  for a mechanism-A migration binary.

## Proof Method

| Leg | Method | Tool | Coverage | Status |
|-----|--------|------|----------|--------|
| Pre-shell classifier rejection | integration | fixture table of rejected command strings run through the ADR-052 §Decision 5c full-command classifier (path arguments, `--cycle` flags, extra flags, shell metacharacters `&&`/`;`/`\|`/backgrounding, compound commands) | every fixture is rejected before the binary is dispatched; zero filesystem mutation | feasible-pending-harness (F4 registry/dispatcher code) |
| Binary-level rejection (defense-in-depth) | integration | direct invocation of the compiled `factory-dispatcher backfill-append-logs <bad-args>` binary bypassing the classifier, against the same fixture table | binary exits non-zero for every fixture outside the two accepted forms; zero filesystem mutation | feasible-pending-harness (F4 code) |
| Accepted-forms positive control | integration | direct invocation with EXACTLY `backfill-append-logs` and `backfill-append-logs --census` | both accepted forms proceed past argument validation (into the migration/census flow respectively) | feasible-pending-harness (F4 code) |

### Why integration (fixture-table dispatch)

Grammar rejection is a property of two real enforcement surfaces — the dispatcher's pre-shell
classifier (a native admission-gate component) and the compiled binary's own argument parser — that
must each be exercised against realistic, adversarially-chosen command strings (including shell
metacharacters and compound commands an attacker or a mistaken agent might construct). This
requires dispatching real fixture strings through the real classifier and the real binary, not a
pure unit test of an isolated parsing function in insolation from the dispatch surface it protects.
The two-layer structure (classifier + binary) mirrors this project's existing
capability-deny-by-default pattern (VP-005/VP-006 — shell-interpreter and setuid/setgid rejection),
which is why this VP is classified `type: safety` rather than `type: invariant`.

## Proof Harness Skeleton

```rust
// crates/factory-dispatcher/tests/backfill_append_logs_grammar_rejection_test.rs
// VP-145: BC-1.18.013 Precondition 3/PC6/INV5/EC-008 — closed-grammar rejection

const REJECTED_FORMS: &[&str] = &[
    "backfill-append-logs /some/other/cycle/decision-log.md",   // path argument
    "backfill-append-logs --cycle v1.0-brownfield-backfill",     // --cycle flag (superseded AC-001(b))
    "backfill-append-logs --force",                              // unrecognized flag
    "backfill-append-logs && rm -rf /",                          // compound command
    "backfill-append-logs; echo pwned",                          // compound command
    "backfill-append-logs | tee /tmp/out",                       // pipe
    "backfill-append-logs --census --extra",                     // extra token after accepted form
];

#[test]
fn test_bc_1_18_013_ec008_pre_shell_classifier_rejects_every_bad_form() {
    for cmd in REJECTED_FORMS {
        let decision = adr052_full_command_classifier::classify(cmd);
        assert!(matches!(decision, ClassifierDecision::Reject { .. }), "accepted bad form: {cmd}");
    }
}

#[test]
fn test_bc_1_18_013_ec008_binary_level_rejection_is_defense_in_depth() {
    for cmd in REJECTED_FORMS {
        let output = run_dispatcher_binary_bypassing_classifier(cmd);
        assert_ne!(output.exit_code(), 0, "binary accepted bad form: {cmd}");
        assert!(!output.any_filesystem_mutation_occurred());
    }
}

#[test]
fn test_bc_1_18_013_accepted_forms_proceed() {
    assert!(matches!(
        adr052_full_command_classifier::classify("backfill-append-logs"),
        ClassifierDecision::Accept
    ));
    assert!(matches!(
        adr052_full_command_classifier::classify("backfill-append-logs --census"),
        ClassifierDecision::Accept
    ));
}
```
