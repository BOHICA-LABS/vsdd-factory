# VP-147: B2 BC-INDEX Shard-Migration Crash-Recovery and Admission-Gate Decision Core — Six Kani Obligations (the `obl1_kani_proofs` Suite)

## Property Statement

The pure, zero-I/O crash-recovery and admission decision core of the governed B2 migration
(`migrate-bc-index`, BC-1.18.011) — `recover`, `classify_txn_records`, the modeled txn-record
state machine, the REAL admission predicate `is_bc_index_admission_open`, and the abstract
two-namespace (`live`/`durable`) `Fs` crash model — is proven correct by bounded model checking
(Kani/CBMC), not sampled. This is the B2 original that VP-146 mirrors for mechanism-A, and the
Kani prong of ADR-052 §Decision 12's two-pronged split (the fault-injection prong is VP-133 facet
2 plus the 30-test `bc_1_18_011_b2_migration_crash_injection_test.rs`).

Six obligations (h1..h6), realized today as SEVEN `#[kani::proof]` functions (h3 carries two: a
single-step inductive harness and a bounded-sequence harness). The CI job is the `kani` job in
`.github/workflows/kani.yml` ("kani (OBL-1 crash-recovery proofs)"): `cargo kani -p
factory-dispatcher --harness proof_obl1` (a SUBSTRING filter) with an `EXPECTED_PROOFS=7`
anti-silent-partial-verification guard that fails the job if the number of successful proofs
differs. The constant MUST change in the same commit as any harness addition/removal.

| Obl. | Harness (current) | Property | BC anchor (clause text verified to exist in BC-1.18.011 v1.11) |
|------|-------------------|----------|-----------|
| h1 | `proof_obl1_h1_recover_totality` | `recover` over arbitrary bounded `(canonical_hash, staging_hash, record)` inputs always terminates in exactly one recovery decision; never panics, never `unreachable!()`. | Precondition 5 (intent log + matching-hash rule), EC-002, EC-003 |
| h2 | `proof_obl1_h2_recovery_safety_predicate` | Every reachable durable outcome resolves old-or-new-committed, never torn/partial; hash-keyed (content-verified), not existence-keyed. | Precondition 5, Postcondition 3, Invariant 3, EC-002 |
| h3 | `proof_obl1_h3_transition_inductive_step` + `proof_obl1_h3_transition_bounded_sequence` | Txn-record state machine (ADR-052 §7a: STAGING/COMMITTING/COMPLETED/ABORTED) transition totality and inductive-invariant preservation; progress rank monotonic; terminal states absorbing; bounded multi-step sequence. | Precondition 5 (states), Invariant 3 ("no turning back"), Postcondition 4 (ABORTED) |
| h4 | `proof_obl1_h4_admission_gate_invariant` | INV-GATE-TXN: no writer is admitted while the gate is DRAINING/LOCKED and/or the txn is STAGING/COMMITTING, over a finite scheduler of {AdmitWriter, ReleaseWriter, BeginDrain, CompleteDrain, advance/finish-and-reopen} (≤ 6 steps, writer counter ≤ 3); admission decided by the REAL `is_bc_index_admission_open`. | Precondition 6(b), Precondition 6(c) **(pre-v1.11 drain/reopen lifecycle only — see "Not proved by the existing suite")** |
| h5 | `proof_obl1_h5_pointer_swap_crash_atomicity` | Bounded symbolic crash trace over `InMemoryFs`: `recover` applied to the post-crash durable state converges to exactly the OLD or NEW generation (never torn); the commit predicate fires only on the `pointer_swap` op; WAL ordering (every INTENT record fsynced before the pointer swap) — before/after regression pair for the ADR-052 §7b ordering fix. | Precondition 5, Postcondition 3, Invariant 3, EC-002 |
| h6 | `proof_obl1_h6_recovery_idempotence` | `recover` → apply decision → `recover` again converges to the same (or next-table-row-deterministic) decision; never a repeated destructive action. | Postcondition 5, EC-003, EC-006 |

**Defensible claim form (verbatim from the harness module doc):** *under abstract filesystem
model M, every modeled op/crash sequence of length <= N preserves the old-or-new invariant and
recovery is total and fail-closed.*

**Scope boundary (what this VP does NOT claim).** Kani has no semantics for `rename(2)`,
`F_FULLFSYNC`, the page cache, torn sectors or power loss; the real-OS refinement of the `Fs`
model's axioms (two-namespace live/durable; atomic rename) is the 30-test fault-injection suite
(and VP-133 facet 2). Per-BC-row content preservation is VP-132; census/atomicity/idempotency on
the real substrate and facets 6-8 are VP-133.
