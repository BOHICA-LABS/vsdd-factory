# VP-131: BC-INDEX changelog: rotate_changelog Failure Fails Loud as HookResult::Error (E-SHD-004 on the Err arm; E-SHD-014 on an Ok(mutated=false) counter-divergence); Frontmatter Left in Its Pre-Rotation State

## Property Statement

Mechanism B1's rotation failure path is loud and leaves no partial state — the exact symmetric
counterpart of mechanism A's shard-seal-write fail-loud leg (VP-120), the backfill-split preservation-gate
fail-loud leg (VP-124), and the retention missing-index fail-loud leg (VP-122). Every mechanism-A
fail-loud path (E-SHD-001 → VP-120, E-SHD-002 → VP-122, E-SHD-003 → VP-124) has a verification
property; this VP closes the parallel gap for B1's `rotate_changelog`-failure path (E-SHD-004).
As of the cluster-4 hardening (Obs A), this VP additionally covers B1's SECOND fail-loud outcome —
the `Ok`-arm counter-divergence guard (`E-SHD-014`, point 4): a fired trigger paired with
`rotate_changelog_at` returning `Ok(report)` where `report.mutated == false` is ALSO fail-loud
(the `Error` variant — dispatched BLOCKING, same as `E-SHD-004` — never the `HookResult::Block`
retry variant), completing the rotation step's fail-loud coverage across both the `Err`
arm (point 1, `E-SHD-004`) and the `Ok(mutated=false)` arm (point 4, `E-SHD-014`).

1. **rotate_changelog failure is HookResult::Error, never Block, never Continue.** When the gate's
   B1 handler invokes `rotate_changelog(..., keep_recent = low_water_mark, ...)` on an over-N
   `changelog:` prepend — trimming toward the CONFIGURED `low_water_mark` (default `floor(N/2)`,
   BC-1.18.005 §Postcondition 8; NEVER a hardcoded `N-1`) — and that invocation itself fails (e.g.,
   the append to the SINGLE evergreen archive file
   `.factory/specs/behavioral-contracts/BC-INDEX-changelog-archive.md` cannot be written — disk
   full, permission error), the gate returns `HookResult::Error` (taxonomy `E-SHD-004`) — NOT
   `Block` (a normal
   successful rotation's outcome, VP-125's block-and-retry path) and NOT `Continue` (which would let
   an unrotated, over-N write proceed) (BC-1.18.009 §EC-003, §Postcondition 6). The fail-loud outcome
   is INDEPENDENT of the trim target: it holds identically for any valid `low_water_mark`, and this
   VP asserts no fixed `N-1` post-rotation floor.

2. **Pre-rotation state preserved; the triggering prepend is not applied.** On a `rotate_changelog`
   failure the live frontmatter `changelog:` sequence is left byte-for-byte in its pre-rotation
   state: no partial trim, no partial archive append treated as authoritative, and the agent's own
   pending prepend is NOT applied by the gate (the gate never prepends — VP-126) (BC-1.18.009
   §EC-003 "the frontmatter is left in its pre-rotation state", §Postcondition 6 fail-loud). This is
   the item-count-shape analogue of VP-120's "no shard-index entry is published and the canonical
   file is left in its pre-roll state."

3. **The error is specific, never generic.** The `HookResult::Error` message names the artifact and
   the failing operation (`E-SHD-004: rotate_changelog invocation failed for "<artifact>": <io-error>`,
   `E-SHD-004` per `error-taxonomy.md`) — never a generic "write failed." This extends to the
   `E-SHD-014` message of point 4, which names the artifact and describes the counter-method
   divergence, never a generic error.

4. **`Ok(report)` with `report.mutated == false` after a fired trigger is ALSO fail-loud —
   `HookResult::Error` (`E-SHD-014`), never `Block` (NEW, cluster-4 hardening Obs A; BC-1.18.009
   §EC-008 / §Invariant Inv-5 / §Postcondition 6 addendum).** When the B1 handler's item-count
   trigger fires (`read_changelog_item_count` serde count `>= N`) but `rotate_changelog_at` returns
   `Ok(report)` with `report.mutated == false` — its own `parse_frontmatter` line-scan counted
   `total <= keep_recent`, a counter-method divergence between the serde trigger path and the
   line-scan no-op guard — the gate MUST return `HookResult::Error` (taxonomy `E-SHD-014`), NEVER
   the `HookResult::Block` retry variant. **`E-SHD-014` is dispatched BLOCKING — `block_intent=true`,
   `exit_code=2`, `on_error=Block`, the SAME blocking treatment as `E-SHD-004` (BC-1.18.009 v1.6
   block-semantics clarification); "never `Block`" here refers to never emitting the
   `HookResult::Block` retry variant (which carries a retry instruction), NOT to non-blocking
   dispatch — the offending write is still BLOCKED, it is simply blocked via the fail-loud `Error`
   channel rather than the retry channel.** Emitting the `Block` retry variant here would falsely
   claim rotation occurred; because the source is unchanged, the item-count trigger re-fires on every
   subsequent dispatch and the gate would again claim rotation, sending the retrying agent into an
   infinite block+retry self-DoS on `BC-INDEX.md` for the session duration. The `Ok(report) if !report.mutated => Error(E-SHD-014)` guard arm
   intercepts this before `Block` is emitted. This leg is the `Ok`-arm SIBLING of point 1's `Err`-arm
   guard: both are fail-loud outcomes of the rotation step (§Postcondition 6 addendum groups them),
   with different guard conditions — point 1 fires when `rotate_changelog_at` returns `Err` (I/O or
   validation failure, `E-SHD-004`), this leg fires when it returns `Ok(mutated=false)` (`E-SHD-014`).
   It is DISTINCT from §Invariant 4, which governs the `mutated=true` `Ok` case (the normal successful
   rotation → `Block`, VP-125's path). As in point 2, on this `Error` the live frontmatter
   `changelog:` sequence is left byte-for-byte in its pre-attempt state and the agent's own prepend is
   NOT applied. The error code is `E-SHD-014` (error-taxonomy.md's authoritative next-free slot)
   — NOT `E-SHD-008`, which the cluster-4 hardening design doc cited as the "next free slot" before
   that assessment was corrected (`E-SHD-008` = `BackstopProbeFailed`, already allocated at taxonomy
   v1.3; codes run through `E-SHD-013`).

### Why unit-test

The failure path is a single injected error condition on a pure, deterministic handler branch — a
hand-crafted table over {rotate succeeds → Block (VP-125's path), rotate fails → Error} gives
exhaustive coverage of the fail-loud branch with no value space a generator would broaden. This
matches VP-120's unit-test rationale for the symmetric mechanism-A shard-seal-write fail-loud leg exactly
(single injected FS error, deterministic branch).

// crates/factory-dispatcher/tests/shard_b1_rotate_failure_test.rs
// VP-131: BC-1.18.009 EC-003 / PC6 — rotate_changelog failure fails loud (E-SHD-004)

#[test]
fn test_BC_1_18_009_EC003_rotate_changelog_failure_is_error_not_block_or_continue() {
    let fs = MockFs::failing_archive_append();             // disk-full / permission on the evergreen archive append
    let r = shard_manager::b1_handle_changelog_overflow("BC-INDEX", &fs);
    assert!(matches!(r, HookResult::Error { .. }));        // E-SHD-004, fail-loud

    assert!(!matches!(r, HookResult::Block { .. } | HookResult::Continue));
    if let HookResult::Error { message } = r {
        assert!(message.contains("rotate_changelog") && message.contains("BC-INDEX"));
    }
}

#[test]
fn test_BC_1_18_009_EC003_frontmatter_left_in_pre_rotation_state_on_failure() {
    let fs = MockFs::failing_archive_append();
    let before = fs.read_frontmatter_changelog("BC-INDEX");
    let _ = shard_manager::b1_handle_changelog_overflow("BC-INDEX", &fs);
    assert_eq!(fs.read_frontmatter_changelog("BC-INDEX"), before);  // byte-for-byte pre-rotation
    assert!(fs.no_partial_archive_append_promoted());             // no partial evergreen-archive append authoritative
}

// VP-131 point 4 (Obs A): counter-divergence guard — Ok(mutated=false) after a fired trigger
// fails loud as E-SHD-014, never Block (BC-1.18.009 EC-008 / Inv-5).
#[test]
fn test_BC_1_18_009_EC008_ok_mutated_false_is_error_e_shd_014_not_block() {
    // Trigger fires (serde read_changelog_item_count >= N) but rotate_changelog_at returns
    // Ok(mutated=false) — its parse_frontmatter line-scan counted total <= keep_recent.
    let fs = MockFs::changelog_at_or_over_n();                     // serde item count >= N
    let rotate = stub_rotate_ok_mutated_false();                  // Ok(RotationReport { mutated: false, items_moved: 0 })
    let before = fs.read_frontmatter_changelog("BC-INDEX");
    let r = shard_manager::b1_handle_changelog_overflow_with("BC-INDEX", &fs, rotate);
    assert!(matches!(r, HookResult::Error { .. }));               // E-SHD-014, the Error VARIANT
    // NEVER the HookResult::Block RETRY variant (the false-rotation infinite block+retry self-DoS
    // Inv-5 forbids), never Continue:
    assert!(!matches!(r, HookResult::Block { .. } | HookResult::Continue));

    assert_eq!(dispatch.exit_code, 2);
    if let HookResult::Error { message } = r {
        assert!(message.contains("E-SHD-014") && message.contains("BC-INDEX"));
    }
    assert_eq!(fs.read_frontmatter_changelog("BC-INDEX"), before); // pre-attempt state preserved
}
