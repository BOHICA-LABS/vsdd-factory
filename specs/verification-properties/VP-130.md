# VP-130: Cohort B Fail-Closed Flip Is Sequenced After BC-1.18.008 Backfill-Split Completion With Per-Validator Calibration Evidence

## Property Statement

The Cohort B flip is safe only because it is sequenced after the backfill-split and gated on
per-validator calibration.

1. **Sequencing gate.** The registry change that assigns `failure_policy = "fail-closed"` to the
   three Cohort B entries never lands before (or in the same commit/release as) BC-1.18.008's
   backfill-split completion (BC-7.08.001 §Postcondition 2, §Precondition 3, §Invariant 2). The flip
   is a SUBSEQUENT deployment, after production observation confirms the shard-capped corpus no
   longer produces `cause=fuel` INDETERMINATE events for these three plugins. Flipping before the
   pre-existing oversized files are split would immediately re-trigger the exact INDETERMINATE loop
   Layer 2 exists to eliminate (BC-7.08.001 §EC-001).

2. **Per-validator calibration evidence.** For each of the three validators, the PR that performs
   the flip records the validator's measured fuel consumption against the largest POST-SPLIT shard
   for every artifact it reads, and confirms it is comfortably under `PRACTICAL_FUEL_CEILING`
   (BC-1.18.005's F4-locked value) — per ADR-039 §Decision 3's calibration-precedes-flip discipline.
   Calibration may pass per-validator independently (a validator whose calibration fails has its
   flip deferred — §EC-003), so the three do not flip atomically in lockstep.

The `PRACTICAL_FUEL_CEILING` value and the post-split shard sizes are **PROVISIONAL-until-F4**; this
VP proves the sequencing/ancestry relationship and the presence of calibration evidence, which are
structural and independent of the numeric ceiling.

## Proof Method

| Leg | Method | Tool | Coverage | Status |
|-----|--------|------|----------|--------|
| Sequencing gate | integration / process | CI or PR-template gate | the backfill-split PR's merge SHA is an ancestor of the Cohort B flip PR; the flip commit does not co-occur with the backfill | feasible-pending-harness (F4 process) |
| Per-validator calibration evidence | integration | PR-evidence check against a `VSDD_SINK_FILE` fuel capture per validator | measured fuel per validator < `PRACTICAL_FUEL_CEILING` on the largest post-split shard; evidence present in the flip PR | feasible-pending-harness (F4 process) |

### Why integration / process

The sequencing gate is a git-ancestry / release-ordering property between two PRs — a process check
(CI gate or PR-template requirement asserting the backfill merge SHA is an ancestor of the flip),
not a code unit test. The calibration leg is an integration measurement (fuel captured via
`VSDD_SINK_FILE` against real post-split fixtures), the same measurement discipline ADR-039 §D3 and
ADR-042 already use for Cohort A.

## Proof Harness Skeleton

```bash
# ci/checks/vp130_cohort_b_sequencing_gate.sh
# VP-130: BC-7.08.001 PC2/PC3/PRECOND3/INV2/EC-001

set -euo pipefail
# (1) Sequencing: backfill-split PR merge SHA MUST be an ancestor of the Cohort B flip commit.
BACKFILL_SHA="$(backfill_split_merge_sha)"    # BC-1.18.008 completion evidence
FLIP_SHA="$(cohort_b_flip_commit_sha)"
git merge-base --is-ancestor "$BACKFILL_SHA" "$FLIP_SHA" \
  || { echo "FAIL: Cohort B flip is not sequenced after backfill-split (VP-130/INV2)"; exit 1; }

# (2) Per-validator calibration evidence present and under the ceiling.
for v in validate-burst-log regression-gate convergence-tracker; do
  fuel="$(measured_fuel_against_largest_post_split_shard "$v")"   # from VSDD_SINK_FILE capture
  [ "$fuel" -lt "$PRACTICAL_FUEL_CEILING" ] \
    || { echo "FAIL: $v calibration not under ceiling — flip deferred (EC-003)"; exit 1; }
done
echo "PASS: VP-130 sequencing + per-validator calibration hold"
```
