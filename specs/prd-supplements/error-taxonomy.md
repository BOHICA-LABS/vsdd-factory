## Error Categories

| Category Code | Category | Description |
|--------------|----------|-------------|
| REG | Registry errors | Hook registry parsing/validation failures (schema version, tool regex, unknown fields) |
| PAY | Payload errors | Malformed or incomplete tool-call payloads reaching the dispatcher |
| CAP | Capability denial | Host-function calls denied by the plugin's declared capability set |
| PLG | Plugin execution | Timeout, crash, or resource-exhaustion outcomes during WASM plugin execution |
| SNK | Sink errors | Event-sink (JSONL/OTLP) write or routing failures |
| ACT | Activation errors | Platform/binary/hooks.json activation failures |
| HK | Hook gate blocks | PreToolUse gate blocks (secrets, destructive commands, branch protection) |
| SHD | Shard management errors | Layer-2 artifact-sharding failures (rotation, backfill, migration) — native dispatcher `HookResult::Error` outcomes, not process exit codes |
| MIG | Migration binary exit codes | Process exit codes emitted by the governed one-time shard migration binary (`factory-dispatcher migrate-bc-index`, `backfill-append-logs`) invoked via one-time interactive Bash approval (ADR-052 §Decision 1). NOT HookResult outcomes — these are process exit codes returned to the Bash tool caller. Exit 2 = error abort (unexpected termination due to integrity, capacity, or timing failures; re-activation required after investigating root cause); exit 1 = expected non-error termination (activation window elapsed; no canonical paths changed; re-activation accepted without error investigation); exit 0 = non-error sentinel (idempotent). |
| MAINTENANCE | Migration window guards | BC-INDEX path writes blocked during an active one-time migration window by dual independent mechanisms: (1) the txn record at `.factory/migration-state/txn-*.json` in state STAGING or COMMITTING — the native admission gate in `executor.rs` (ADR-052 §Decision 5a) blocks ALL mutation tool calls (Edit, Write, MultiEdit, Bash) when this state exists, regardless of PID liveness, firing before any registry plugin; (2) the OPEN/DRAINING gate state (ADR-052 §Decision 5a) prevents new writer reservations when the migration coordinator has declared maintenance intent (gate state = DRAINING or LOCKED). The `validate-factory-path-staging` guard (ADR-052 §Decision 5c, Bash path) is a secondary classifier layer that enforces the full-command classifier and four-branch guard logic. Per BC-1.18.011 Precondition 6 (ADR-052 §Decision 5a/7a). |

## Severity Definitions

| Severity | Meaning | Exit Code / HookResult Impact |
|----------|---------|-------------------------------|
| broken | Cannot continue | Non-zero exit, OR (for E-SHD) `HookResult::Error` — the triggering write is blocked and no partial state is left authoritative |
| blocked | Explicitly denied by policy | Exit 2 |
| degraded | Partial result possible | Zero exit with warnings, non-blocking |
| cosmetic | Formatting/display issue | Zero exit |
