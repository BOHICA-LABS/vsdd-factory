# M1: The sync
<!-- generated: start -->
## Delivers

The function `vsdd.state.sync` and the command `vsdd sync`: the lock that keeps one sync to a clone, the
full and the partial flush, the listing, the fetch into the remote-tracking ref, the combine built path
by path without touching the mount, the push that names the head it was built on, and the outcome in
the clone record. The one function that lists changed paths with rename detection off, and the one
that looks a branch up on the remote by its exact name. The field of
the job specification that keeps a finished sync from being served to a later call. The network form
of the git helper, which cannot wait for a person. The checks of the table sync-checks, and T-LOCAL.
Every fact of the topic team-git-facts as a test, run in CI on Linux with a git at the floor. One
failing and one passing case per refusal. Takes ledger entries D33-3, D33-29 and D33-31, the `sync`
half of D33-4, and the fetch half of P3OPS-13
