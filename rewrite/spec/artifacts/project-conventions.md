# Conventions
The machine row for this kind - path, identifier, frontmatter keys, cap, writer and lifecycle - is its row in [[table:artifacts]].

`conventions.md` is one of the two `guidance` files: named apart inside `spec-arch` because the lock, the
decision digest and the `code-reviewer`'s read wall treat it apart. It is locked with the specification set
while a cycle is open and writable by the architect between cycles, which is when a retrospective's
proposals are adopted ([[topic:spec-lock]]). Adopting a proposal is an edit through
`/vsdd-factory:author conventions`.

A retrospective ([[artifact:research-report]]) names the line each of its proposals would add here.
