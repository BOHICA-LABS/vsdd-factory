# Screen
The machine row for this kind - path, identifier, frontmatter keys, cap, writer and lifecycle - is its row in [[table:artifacts]].

`active` is one of the statuses an agent writes for the living kinds ([[topic:computed-status]]). The three
UI labels local to a screen stay as plain labels inside the screen file and are not checked
([[table:identifiers]]). Screens are in the class `spec-ux` and are locked with the specification set
([[topic:spec-lock]]).
