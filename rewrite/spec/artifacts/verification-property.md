# Verification property
The machine row for this kind - path, identifier, frontmatter keys, cap, writer and lifecycle - is its row in [[table:artifacts]].

A property names its contracts; nothing stores the reverse ([[topic:artifact-rules]]). A withdrawn or
retired property keeps its file and identifier.
