# UX overview
The machine row for this kind - path, identifier, frontmatter keys, cap, writer and lifecycle - is its row in [[table:artifacts]].

`active` is one of the statuses an agent writes for the living kinds ([[topic:computed-status]]). UX files
are in the class `spec-ux` and are locked with the whole specification set ([[topic:spec-lock]]). Screens
and flows are [[artifact:screen]] and [[artifact:flow]]; the design system is [[artifact:design-system]].
