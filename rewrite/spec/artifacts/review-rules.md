# Review rules
The machine row for this kind - path, identifier, frontmatter keys, cap, writer and lifecycle - is its row in [[table:artifacts]].

Like `conventions.md`, `review-rules.md` is one of the two `guidance` files: locked with the specification
set while a cycle is open, writable by the architect between cycles, outside the `spec` decision's digest,
and treated apart by the `code-reviewer`'s read wall ([[topic:spec-lock]]).

A retrospective ([[artifact:research-report]]) names the line each of its proposals would add here; adopting
one is `/vsdd-factory:author review-rules`.
