## After the round-4 probes

Round 4 and its independent check ran on 2026-11-24 (`rewrite/spike/probes-round-4/CHECK.md`; Claude Code 2.1.331, macOS, a plugin loaded by `--plugin-dir`, default permission mode). Item numbers are those of `rewrite/spec/topics/platform-proven-2.md`. What they changed in `agents.md`:

- **PR4C-09, a commit the sandbox refuses (item 41).** With the Bash sandbox on, every write under `.git/worktrees/` is refused, so no builder can `git add` or `git commit` in a story worktree. M2 now says what the agent returns: `blocked`, kind `environment`, with git's line, when a git write is refused with `Operation not permitted`. It does not retry or work round it. The uncommitted work stays in the worktree, and the next run, with the sandbox off, commits it. M2 is common text of every builder method, so it covers the test-writer, the implementer and `fix-findings` step 5.
- **PR4C-13, a call moved to the background (item 43).** A call that outlasts its Bash timeout is moved to the background and killed when the agent gives its final response; the job survives because it is detached. The platform's notice at that moment tells the agent the opposite of what a job command needs: to wait for the result, and not to start a second copy (item 43 quotes it). So M3 gives the rule and its reason in one sentence, which the agent has read before the notice arrives: run the same command again, it re-attaches to the job already running and is not a second copy, and do not wait for or read the background task (`rewrite/spec/topics/long-commands.md`). The clerk's Rules carry the same sentence, and its no-JSON rule speaks of a finished call, so a moved call does not trigger it. Section 7 item 3 checks that `clerk.md` and every `## Finish` that names a gate hold the sentence (`probes-4-apply-C1-2`). The prelude's closing lines are not changed: the method and the clerk file carry the rule. To keep `agents.md` under its size limit, four restatements went with this change and no rule with them: D14 and D16 now point to M1 and to frame item 5, section 2 no longer repeats section 3's rule against copying a wall row, section 1 leaves the spike-runner to D20, and the row saying package A2b has no ledger file is gone.
- **PR4C-05, a block read inside the platform's wrapper (item 40).** An agent reads a hook's block as `PreToolUse:<tool> hook error: [<the hook's command line>]: <message>`, a blank line, then a line naming the plugin. No agent or method file quotes a block today, and section 7 item 3 now checks that none does (`hook error`, `vsdd-factory blocked`): a file says what a hook checks, never how its message starts. The rules unit writes its block texts to stand inside the wrapper (step 4, rules.md D16).
- **PR4C-14, N12 (item 44).** As under PL5-2 above. Section 6 of `agents.md` states what is proven and what is not.
