A decision typed in a session is settled by a hook that cannot reach the network inside its deadline. To publish it at once the rule would start a sync as a detached job of its own, keyed by the command and settle:<decision id> (rewrite/spec/topics/long-commands.md). Whether a hook on that event can leave a detached job behind has not been tried: the proven case is a job started from a Bash call.

The design is correct either way: a settlement is listed as unpublished from the moment it is written, and nothing acts on it until the remote holds it (D33-28).

## PR4-3 (minor; platform probes, round 4; left-for-builder)

Earlier outcome: E2, and every headless driver: enter a workflow through a typed command or skill and check afterwards that the named workflow is what ran (platform item 49).

Files: platform.md, topics/spikes.md

Where it was found: rewrite/spec/topics/spikes.md; the story-ready fixture, E2's first run and the scheduler recipe (step 6, item 25); item 49 of topics/platform-proven-2.md; rewrite/spec/platform.md, 'Headless runs'

A headless main session told to start a named workflow can pass its own inline script instead: the Workflow tool accepts a script field, and the named plugin workflow never runs. Round 4 lost two probe runs to this. Entering through a typed skill that names the workflow does not prevent it: in the check's rerun E the main session, started through the typed skill, still passed an inline script ('return {}'). Seen in the default mode on Claude Code 2.1.331 with a --plugin-dir plugin. Evidence: rewrite/spike/probes-round-4/CHECK.md (rerun E, E-inline-script).

Proposed resolution: A typed skill or command stays the way in, but it is not the check. Every headless driver (the story-ready fixture, E2's first run, scheduler recipes, probe harnesses) verifies that the named workflow ran, by comparing the run record's scriptPath and script with the plugin's file, or a PreToolUse rule refuses a Workflow call that carries script in a driver session. topics/spikes.md names the inline-script shape as the failure this prevents.
