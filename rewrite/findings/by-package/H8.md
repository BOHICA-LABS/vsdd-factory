## P3COV-08 (minor; review pass 3; open)

Where it was found: rewrite/design/hooks.md 2.3 (SubagentStart async), 2.11.6 Who asked row; rewrite/design/state.md 2.16 vsdd spike open; rewrite/BLUEPRINT.md 6, section 10 item 35

For a spike runner dispatched with the Agent tool, the admission is paired with the runner in an async SubagentStart hook. Nothing orders that before the runner's first vsdd spike open, which refuses when no asker can be established. Proposed resolution: Have vsdd spike open claim the oldest unclaimed admission of the caller's session itself when the marker's agent id has none, or do the pairing in the synchronous PreToolUse rule on the runner's first guarded call. Add the ordering case to probe 35.
