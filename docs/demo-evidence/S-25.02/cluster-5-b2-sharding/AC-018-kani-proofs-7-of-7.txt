## What each harness proves (per obl1_kani_proofs.rs's own header, research
   report §5a items 1-6)

- proof_obl1_h1_recover_totality: the crash-recovery `recover` function is
  TOTAL over every reachable txn-record + intent-log state -- it never
  panics and never returns an unhandled state for any input in its bounded
  domain.
- proof_obl1_h2_recovery_safety_predicate: recovery never produces an
  unsafe outcome (e.g. treats a move as "done" only when the canonical
  post-hash actually matches).
- proof_obl1_h3_transition_bounded_sequence / h3_transition_inductive_step:
  the txn state machine's transitions are bounded and the inductive step
  (one valid transition from any reachable state leads only to another
  valid state) holds.
- proof_obl1_h4_admission_gate_invariant: the BC-INDEX admission gate's
  open/closed invariant (INV per PRECOND6BC) holds across every txn state.
- proof_obl1_h5_pointer_swap_crash_atomicity: the pointer-swap commit point
  is atomic across a crash at every modeled interruption point -- there is
  no reachable state where a crash mid-swap leaves a torn/ambiguous
  canonical pointer.
- proof_obl1_h6_recovery_idempotence: running `recover` twice from the same
  on-disk state is idempotent (second call is a no-op / converges to the
  same terminal state as the first).
