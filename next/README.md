# vsdd-factory

Verification-Specification-Driven Development for Claude Code: specifications, stories,
test-first delivery, adversarial review, holdout evaluation and release gating, run by workflows
and enforced by hooks.

This file is finalized in the documentation package (D3). Until then, `rewrite/STATE.md` at the
repository root is the record of the rewrite, and `rewrite/BLUEPRINT.md` is the design.
